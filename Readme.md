# 🚀 LeetCode Metrics Tracker

A web application that displays LeetCode statistics through an interactive dashboard, allowing users to track problem-solving progress and submission metrics.

## 🌐 Live Demo

https://jishnup17.github.io/-LeetCode-Metrics/

---

## 📖 About the Project

This is my first frontend project built after learning HTML, CSS, and JavaScript.

The application allows users to enter a LeetCode username and instantly view coding statistics, including solved problems by difficulty level and overall submission data.

Building this project helped me gain practical experience with frontend development, API integration, asynchronous JavaScript, and dynamic UI rendering.

---

## ✨ Features

* Search for any valid LeetCode username
* View solved problems by difficulty:

  * Easy
  * Medium
  * Hard
* Interactive circular progress indicators
* Track overall submission statistics
* Dynamic UI updates without page reloads
* Username validation using Regular Expressions (Regex)
* Real-time data fetching using Fetch API and GraphQL

## ⚠️ Important Note

This project uses a CORS proxy service to access LeetCode data from the browser.

If statistics are not loading, visit the CORS proxy access page and enable temporary access before using the application:

https://cors-anywhere.herokuapp.com/corsdemo
